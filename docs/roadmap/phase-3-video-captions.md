# Phase 3: Caption-based video learning (planned)

Start with accessible existing German captions through isolated platform adapters. Permit clickable words, an optional hidden translated line, timestamped saving, phrase replay, and caption-derived cards. Preserve timestamps as occurrences and avoid storing/redistributing complete copyrighted subtitle tracks.

Acceptance requires explicit supported-platform tests, original playback preservation, reliable stop/cleanup, no DRM bypass, and honest unsupported-site messaging. Universal compatibility is not promised. No Phase 3 code exists yet.
