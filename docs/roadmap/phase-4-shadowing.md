# Phase 4: Shadowing trainer (planned)

Learning sequence: Listen → read/understand → echo after a pause → shadow simultaneously → hide subtitles → record → compare → self-rate → schedule repetition.

Plan A–B looping, phrase segmentation, playback speed, automatic pause/delay, original/user playback, explicit recording, transcript comparison, repeat counts, playlists, and keyboard controls. Recording must be opt-in with visible state and deletion. Transcript similarity is feedback, not a precise pronunciation score. No Phase 4 code exists yet.
