# Phase 2: Assisted webpage reading (planned)

On explicit user action and optional per-site permission, provide temporary hover help, paragraph translation, known-word re-encounter and difficult-word highlighting, sentence analysis, phrase mining, and a page learning summary. Apply a visible translation budget and keep translations hidden by default; never replace the entire page automatically.

Acceptance requires permission revocation, bounded DOM processing, dynamic-page cleanup, per-site controls, no HTML injection, accessible overlays, budget enforcement, and tested Chrome/Opera degradation. No Phase 2 code exists yet.
